# Team

- **lagerard**: the game with the MLX: config, mazes, characters,
  rules, display, menus, highscores, cheat mode, documents.
- **tmagoudi**: Looney Tunes images and animations, transformation of the
  whole game into pygame, merge of the two versions.

Decisions were taken together (keys, look, rules). Each one worked on a
branch; the branches were merged with pull requests on GitHub. The
subject rule on MLX equivalents was checked after the merge, and the
pygame display was rewritten to respect it.
